# Recipe Box — overview

A tiny web app for keeping your favourite recipes in one place. It's the
**sample project** that ships with Aura so you can see every part of the app
working on real content before you point it at your own code.

## What it is

Plain HTML, CSS and JavaScript — no build step. Open `index.html` and it runs.
The page shows a grid of recipe cards and a light/dark toggle.

## Where things are

- **Build** — the chat. There's a finished conversation (Claude Code added the
  dark mode) and a live one (an agent adding search right now).
- **Plan** — this page, plus the task board: one change done, one in progress,
  one waiting.
- **Team** — the people and agents who've touched this project.
- **Trace** — the reason behind each change, in plain words.

## What's next

Search is nearly in. After that: letting people ♥ their favourites. Both are on
the task board — pick one up whenever you like.
